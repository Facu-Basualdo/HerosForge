**Regla absoluta:** el cliente no decide nada. Muestra el `Paquetes.Estado` que manda el servidor y le pide las compras; el servidor valida y cobra igual que desde el cofre. Todo esto es opcional: el mod tiene que andar igual con un cliente vanilla.

No agregues documentación a este archivo: cada tema va como una nota.
